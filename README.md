# vrOS Support Center

Support surface for [support.vros.cat](https://support.vros.cat).

## Stack

- Vite 7
- React 19
- vrOS design-system v2 tokens and components
- Existing `api/` Cloudflare Worker retained for bug-intake compatibility

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
